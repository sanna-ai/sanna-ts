# @sanna-ai/gateway

MCP enforcement proxy for the [Sanna protocol](https://github.com/sanna-ai/sanna-ts).

## Usage

Typically driven via the `sanna gateway` command from `@sanna-ai/cli`:

```
sanna gateway <config>
```

Or invoked directly:

```
sanna-gateway <config>
```

For full usage see the
[repository README](https://github.com/sanna-ai/sanna-ts#readme).
