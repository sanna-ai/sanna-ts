# @sanna-ai/cli

The `sanna` CLI for the [Sanna protocol](https://github.com/sanna-ai/sanna-ts) --
trust infrastructure for AI agents.

## Install

```
npm install -g @sanna-ai/cli
```

## Usage

```
sanna --help
```

For the full command reference see the
[repository README](https://github.com/sanna-ai/sanna-ts#readme).
